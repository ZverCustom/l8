# L8 v3: проверка прошивки 2026-11-20

Версия `0.3.0-dev`, рабочая ветка `fw-v3`. Плата ESP32-S3 rev 0.2,
flash 16 МБ, Quad PSRAM 2 МБ. Прошивка записана по native USB;
esptool подтвердил совпадение контрольной суммы.

SHA-256 `firmware.bin`:

```text
839bef4261d6837318969332086e88c36ccd80ea026883fb0c71a88360ea0bbe
```

## Подтверждено

- Сборка PlatformIO `l8_v3`; JavaScript интерфейса проходит `node --check`.
- [23 native-теста](2026-11-20-fw-v3-native.log): выбор DEN/DSEL для восьми выходов,
  независимые защёлки, ограничения VBAT/IGN, аналоговые и цифровые входы,
  обработка DS2 и существующая логика PowerLatch.
- [33 проверки на плате по USB](2026-11-20-fw-v3-usb.json): готовность I2C и IMU,
  самопроверка памяти, восемь выключенных выходов и DATA, схема конфигурации,
  скрытие пароля, отклонение семи видов некорректной конфигурации без частичного
  применения, проверка команд, сохранение / чтение, запись / загрузка пресета,
  восстановление исходных настроек и их сохранность после перезагрузки.
- Переполнение USB-строки не выполняет её хвост. При проверке обнаружен и исправлен
  слишком маленький стандартный RX-буфер CDC: увеличен с 256 до 32768 байт.
- Wi-Fi подключался к известной сети (по USB-журналу).
- После проверок Master выключен, bench-режим и питание датчиков выключены,
  на всех восьми каналах `on=false`, `data=false`.

Во время проверки полной прошивки силовой вход показывал **0 В**, IGN = 0.
Предыдущая отдельная диагностика с подключёнными 12 В измеряла 11,91–11,92 В
([отчёт](../../diagnostics/v3-usb/README.md)).

## Ещё не подтверждено

- Физический вывод на ленты, задержки DATA относительно ключей по осциллографу,
  калибровка тока, защита под нагрузкой и fault-тесты BTS7008.
- Внешние сигналы трёх входов, питание / fault датчиков.
- Запуск только от 12 В + IGN, отпускание HOLD без USB.
- CAN и K-line с подключённым ЭБУ.
- Резервная точка доступа, HTTP-конфигуратор в браузере, мобильная вёрстка,
  HTTP-команды и OTA с откатом.
  Браузерная проверка остановлена автоматическим правилом доступа: запрет
  адреса устройства и затем адреса локального предпросмотра. Обходы не применялись.
  Первый HTTP-запрос до получения запрета не завершился за 5 секунд; работоспособность
  HTTP по этому запросу не подтверждена. Локальный сервер предпросмотра остановлен.

Это первая прошивка для стендового запуска, не завершённая автомобильная валидация.
