# L8 v3 — независимое питание контроллера, 0.3.1-dev

Плата v3, ESP32-S3-WROOM-1U-N16R2, порт `/dev/cu.usbmodem1101`.
Прошивка собрана и записана через USB; esptool подтвердил хеш записанных данных.
Размер `firmware.bin`: 924336 байт.
SHA-256: `c183d1702904d9a4ba71b4bb0c660d169da62036a7b4b5696d67ea83c88d9f82`.

## Поведение

- HOLD больше не снимается через 0,5 с после выключения IGN. При внешнем питании
  от 6 В контроллер удерживает преобразователь включённым независимо от Master,
  IGN и защит нагрузок. При USB без внешнего питания HOLD остаётся низким.
- `global.allowWithoutIgn` управляет только питанием лент. CAN и питание датчиков
  не зависят от IGN, сохраняя собственные настройки и общие блокировки.
- В интерфейсе: «Система → Питание и запуск → Ленты работают без IGN».
  Заводское значение — включено; существующие конфигурации сохраняют своё значение.
- На подключённой плате значение изменено с `false` на `true`, остальные поля
  конфигурации сохранены. Master и автозапуск выключены.
- В `status` добавлены `allowWithoutIgn` и `ledPowerAllowed`. Последнее отражает
  общие условия разрешения лент, отдельно от Master и защит отдельных каналов.

  блокировки, исправности I2C и наличия питания; отдельные проверки удержания
  контроллера при напряжении вне разрешённого для лент диапазона.
- `pio run -e l8_v3`: успешно. RAM 63396 байт, размер программы 923977 байт.
- JavaScript встроенного интерфейса: `node --check`, успешно.
- `scripts/check_v3_usb.py`: **47/47**, [результат](2026-11-20-fw-v3-ign-usb.json).
  Обе настройки IGN применяются и читаются обратно. При USB без 12 В питание

- После теста: `0.3.1-dev`, `allowWithoutIgn: true`, `master: false`,
  `ign: false`, `hold: false`, `ledPowerAllowed: false`, исправные I2C / IMU,

## Аппаратные ограничения

Изменений платы нет. По схеме v3 EN преобразователя получает сигнал через IGN
или HOLD. После полного снятия питания MCU не может выставить HOLD самостоятельно,
поэтому для холодного запуска нужен USB или IGN. Сброс MCU тоже сбрасывает HOLD.
Прошивка меняет поведение уже запущенного контроллера, а не аппаратную цепь запуска.

Работа преобразователя после отключения USB, ленты под нагрузкой, CAN на машине,
визуальная проверка веб-интерфейса и HTTP OTA этим тестом не подтверждены.
