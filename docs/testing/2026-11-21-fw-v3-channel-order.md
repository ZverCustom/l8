# L8 v3 — порядок каналов, прошивка 0.3.2-dev

Работа выполнена 20–21 ноября 2026. Плата v3 подключена по USB, питание лент —
12 В / 5 А. IGN не подключён. Изменений электрической схемы и разводки нет.

## Изменение

Пользовательские каналы следуют силовым контактам J1. Тройки +12 В / DATA / GND:
`1/10/26`, `2/11/27`, `3/12/28`, `4/13/29`, `6/15/31`, `7/16/32`, `8/17/33`, `9/25/34`.
Питание, GPIO DATA, выбор DEN/DSEL и защита используют одну таблицу
`lib/v3_safety/channel_map.h`. Маска DATA внутри драйвера остаётся физической.

Формат настроек — schema 4. Schema 3 принимается с переносом цветов, длин,
разрешений, калибровки, лимитов тока и пресетов на прежние физические выходы.
Загрузка старого файла сохраняет миграцию атомарно; повторная загрузка schema 4
ничего не переставляет. При импорте старого JSON редактор показывает новый порядок.
Интерфейс выводит номера контактов из API статуса рядом с каждым каналом.

## Проверки

- Native: **26/26**, включая полную таблицу питания / DATA / sense и 256 комбинаций
  разрешённых каналов; отдельная проверка миграции массивов.
- Сборка и USB-запись успешны; esptool подтвердил хеш записанных данных.
  `firmware.bin`: 925488 байт, SHA-256
  `dd90c760a63ce585a13e3d67b561a22f3bd90204ea1fe4426c0e02117656056b`.
- [USB-проверка миграции](2026-11-20-fw-v3-channel-order.json): **25/25**.
  Реальные пользовательские настройки сохранили физическую привязку после прошивки.
  Проверены уникальные параметры всех восьми каналов, пресет, отклонение неверного
  файла целиком и сохранение после перезагрузки. Все выходы при этом выключены.
- JavaScript: синтаксис, миграция schema 3, отсутствие повторной миграции schema 4,
  вывод контактов канала 2. Все 24 контакта таблицы сверены с готовым `.kicad_pcb`.
- [Канал 2 с выбранным синим](2026-11-20-fw-v3-channel2-blue.json): 2/11/27,
  RGB, `#203FBC`, общая яркость 30%, около 11,92–11,93 В и 0,55–0,58 А.
  Пользователь подтвердил синий цвет.
- После подключения другой ленты [проверены оба канала](2026-11-21-fw-v3-both-strips.json):
  канал 1 сначала отдельно, затем оба вместе. При совместной работе около 11,91–11,92 В,
  канал 1 около 0,23–0,33 А, канал 2 около 0,54–0,55 А, ошибок защиты нет.
  Оставлены включёнными каналы 1 и 2; остальные выключены. Измерения тока не калиброваны
  внешним прибором. Ранее наблюдавшаяся просадка при этом подключении не воспроизвелась;
  точная причина прежней просадки не установлена.

Шесть остальных физических нагрузок, HTTP OTA и вид веб-интерфейса в браузере
этой проверкой не подтверждены. Сохранение конфигурации по-прежнему выключает Master.
