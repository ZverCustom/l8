# L8 v3 — применение настроек без отключения Master

21.11.2026, прошивка `0.3.3-dev`, плата v3 без аппаратных изменений.
SHA256 установленного firmware.bin: `e42cef6f0b1afcfda057dab28fb8fc14da55724ef94b4871c07da28ba229842d`.

Сохранение полной конфигурации, импорт и загрузка пресета сохраняют runtime Master.
Изменения применяются под блокировкой LED-кадра; питание не циклируется,
защёлки защиты и действующая блокировка питания не сбрасываются. CAN перезапускается
только при изменении режима/скорости. При уменьшении длины ленты прежний хвост
гасится кадром старой длины перед сменой размера контроллера.

Интерфейс отправляет один запрос для сохранения, не перечитывает конфигурацию и
не теряет правки, сделанные во время запроса. Есть последовательная очередь, тайм-аут,
повтор начального подключения и обновление токена после явного HTTP 403.
Запросы записи с неизвестным результатом автоматически не повторяются.
Wi-Fi подключается только к выбранному SSID; повтор через 10 секунд вместо 30.

## Проверено

- Сборка ESP32-S3 и USB-запись с проверкой хеша прошли.
- 26 native-тестов защит, преобразований, карты каналов и DS2 прошли.
- `node scripts/check_ui.mjs`: запуск UI, один POST, Master on/off, правки во время
  сохранения, тайм-аут/повтор загрузки, обновление сессии, отказ от повтора
  неоднозначной записи, сохранность редактора при потере связи.
- 66 проверок на плате: повторное применение при включённых двух лентах,
  Master on/off, отклонение некорректной конфигурации, IGN-policy, сохранение/загрузка
  пресета, восстановление пользовательских настроек и их сохранность после перезапуска.
  Тестовая яркость не выше 30%, длина не выше 60 LED; после теста настройки восстановлены,
  Master выключен. Тест не имитирует аппаратное короткое замыкание.
- 10 замеров полного `set_config` через USB: медиана
  28.11 мс, диапазон 24.47–35.05 мс.
  Это время приёма/применения и ответа по USB, а не HTTP-задержка или время оптического отклика.
- Пользователь подтвердил открытие интерфейса `0.3.3-dev` в браузере.

Первая проверка сети после программного перезапуска не уложилась в срок; этот
неуспех сохранён в `2026-11-21-fw-v3-live-save.json` (complete=false).
После изменения периода повторного подключения проверена финальная прошивка:
USB-reset — подключение подтверждено на 15078 мс,
software reboot — на 14549 мс uptime.
Оба раза выбранная сеть, настройки сохранены, I2C исправен, Master выключен.
Результат: `2026-11-21-fw-v3-network.json`.
Изменение периода Wi-Fi не меняло уже проверенный код применения настроек.

## Границы

Настройки применяются сразу, запись в LittleFS отложена на 1,5 секунды после последнего
изменения. Поведение при полном обрыве сети и живой HTTP OTA в этом прогоне не проверялось.
Нет осциллографической проверки непрерывности питания во время сохранения.
Клиентский PDF rev 0.4 остаётся описанием ПО 0.3.2; актуальное изменение Master
отмечено в `ZVER/docs/README.md` и README прошивки.
