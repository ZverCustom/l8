# L8 v3 — этапы 0.4

Ветка `fw-v3-next`, отдельная рабочая копия `ZVER/L8-next`, база `497b8e4`.
PCB не меняется. Подготовленная 0.3.4 остаётся в исходной ветке `fw-v3`.
Код всех выбранных этапов реализован; физическая квалификация ожидается.

## Порядок оставшихся этапов

1. Прежние ранние USB-логи 0.3.3/0.3.4 и OTA boot-inhibit, чтобы сохранить исходную диагностику.
2. Новая 0.4 с RMT: настройки/питание/анимации и реальные токовые пороги.
3. AP/STA/SSE/captive portal на телефонах и при потере сети.
4. LCD_CAM: осциллограф, все линии, максимальная длина, отключение DATA во время кадра.
5. Отдельный профиль `l8_v3_dma_flash`: flash/cache-off на максимальном кадре.
6. По результатам решить о DMA по умолчанию и обновить клиентский PDF.

До пункта 5 обычная сборка сохраняет RMT, его патч и исключение flash.
Программные проверки не являются измерением FPS, сетевой задержки или защиты под нагрузкой.
